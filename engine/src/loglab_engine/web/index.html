            Set up an operation

            An operation is one use of an overlay, like Field Day under the club call. Every operator signs in as themselves and picks it from the Menu; each QSO is logged as the station call, with the operator noted on it.

            Import an ADIF file

            Bring in the QSOs from another program's log, such as WSJT-X's wsjtx_log.adi. QSOs LabLog already has (the same call, band and mode in the same UTC minute) are left alone, so you can import the same program's log again later and only its new QSOs come in. A QSO you deleted stays deleted. Every field in the file is kept as it is.

            Log them in

            If your QRZ.com logbook is set up, new QSOs are copied there like typed ones. Nothing goes to LoTW until you press Send there.

              QRZ.com

              Your QRZ logbook

              Each QSO you log from now on is copied to your QRZ logbook, and edits and deletes follow it. Use the API key from your logbook's settings on QRZ.com. With no internet, QSOs wait in LabLog and go out when QRZ.com can be reached; logging never waits on it.

              Callsign lookup

              When you type a call, LabLog asks QRZ.com for the name, QTH, state and grid and fills in any of those boxes you left empty. QRZ.com's lookup takes your QRZ username and password (not the API key) and an XML subscription. US and Canadian calls fill in from LabLog's own copy of the FCC and Canadian lists even with no internet; QRZ.com adds the grid and other countries' calls. With no internet, logging works the same.

              Keeping stored profiles current

              Once a stored profile is a month old, LabLog quietly asks QRZ.com again for its small callsign record, a few seconds apart. It downloads the biography or photo again only when QRZ.com says it changed. Nothing is checked with no internet, and lookups and logging never wait on it.

              Station Agents

              A Station Agent runs on the computer a radio is plugged into and sends LabLog what the radio is doing. A new Agent asks to join and shows a code. Approve it only if the code here matches the one the Agent shows.

                  Clean up saved lookups

                  LabLog keeps every QRZ.com answer it gets, so a call fills in again with no internet. This clears the ones for calls that were never logged. The log is never touched, and a call in any QSO keeps its lookup. A cleared call is just looked up again the next time someone types it.

                  US and Canada call lists

                  LabLog keeps its own copy of the FCC's and Canada's amateur license lists, so US and Canadian calls fill in with no internet. Whenever it can reach them, it loads the FCC's weekly list and each day's changes, and Canada's list. Only the call, name, city, state or province and license class are kept.

                    Logbook of the World

                    Nothing goes to LoTW as you log. When you're ready, LabLog gathers your waiting QSOs into a numbered batch for you to check, and sends that batch, signed with your own LoTW callsign certificate, only when you press Send. Logging never waits for LoTW: with no internet, QSOs simply wait here.
