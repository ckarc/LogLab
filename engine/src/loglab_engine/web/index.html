        Services

        Set up an operation

        An operation is one use of an overlay, like Field Day under the club call. Every operator signs in as themselves and picks it from the Menu; each QSO is logged as the station call, with the operator noted on it.

        QRZ.com

        Your QRZ logbook

        Each QSO you log from now on is copied to your QRZ logbook, and edits and deletes follow it. Use the API key from your logbook's settings on QRZ.com. With no internet, QSOs wait in LogLab and go out when QRZ.com can be reached; logging never waits on it.

        Callsign lookup

        When you type a call, LogLab asks QRZ.com for the name, QTH, state and grid and fills in any of those boxes you left empty. QRZ.com's lookup takes your QRZ username and password (not the API key) and an XML subscription. With no internet, nothing is filled in and logging works the same.

        Logbook of the World

        LogLab signs your QSOs with your own LoTW callsign certificate and sends them when you press Send. Logging never waits for LoTW: with no internet, QSOs simply wait here until you send them.

          Callsign certificate

          In TrustedQSL, pick your callsign certificate and choose Save the callsign certificate. That makes a .p12 file with a password you choose. Pick that file here.

          Station location

          Where the station is. LoTW records this with every QSO you send, like a TrustedQSL station location.

          LoTW website login

          Used only to fetch confirmations: the username and password you use on the LoTW website.
